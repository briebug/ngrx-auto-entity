# Installation

![NPM Version](https://img.shields.io/npm/v/%40briebug%2Fngrx-auto-entity)

To get started, install the package using npm, yarn, or pnpm:

```shell
npm install @briebug/ngrx-auto-entity@19.0.0
```

```shell
yarn add @briebug/ngrx-auto-entity@19.0.0
```

```shell
pnpm add @briebug/ngrx-auto-entity@19.0.0
```

## Requirements

The following peer requirements must also be installed when using NgRx Auto Entity:

| **Package**     | **Required Version** |
| :-------------- | :------------------- |
| `@angular/core` | >= 19.0.0            |
| `@ngrx/effects` | >= 19.0.0            |
| `@ngrx/store`   | >= 19.0.0            |
| `rxjs`          | >= 7.0.0             |

[![Deps-AngularCore](https://img.shields.io/badge/@angular/core-%5E19.0.0-blue.svg)](https://github.com/angular/angular)
[![Deps-AngularCommon](https://img.shields.io/badge/@angular/common-%5E19.0.0-blue.svg)](https://github.com/angular/angular)
[![Deps-NgRxStore](https://img.shields.io/badge/@ngrx/store-%5E19.0.0-blue.svg)](https://github.com/ngrx/platform)
[![Deps-RxJs](https://img.shields.io/badge/rxjs-%5E7.0.0-blue.svg)](https://github.com/reactivex/rxjs)

```shell
npm install @angular/{common,core}@^19.0.0 @ngrx/{effects,store}@^19.0.0 rxjs@^7
```

```shell
yarn add @angular/{common,core}@^19.0.0 @ngrx/{effects,store}@^19.0.0 rxjs@^7
```

```shell
pnpm add @angular/{common,core}@^19.0.0 @ngrx/{effects,store}@^19.0.0 rxjs@^7
```
